# 📊 Sales Performance & Customer Insights

## 📌 Project Overview

This project focuses on analyzing sales performance, product trends, channel performance, and customer insights through an end-to-end data analytics workflow.

The project begins with data cleaning and exploratory data analysis using Python and concludes with the development of an interactive Power BI dashboard. The analysis helps identify key revenue and profit trends, top-performing products, sales channels, regions, and customers.

> **Note:** The dataset used in this project was sourced from external resources and is used solely for learning and portfolio purposes.

---

## 🔄 Project Workflow

**Raw Dataset → Python → Data Cleaning → EDA & Visualization → Power BI Dashboard**

### 1. Data Cleaning using Python

The raw dataset was cleaned and prepared for analysis using:

- Pandas
- Data preprocessing techniques
- Data transformation
- Handling data quality issues

### 2. Exploratory Data Analysis (EDA)

Exploratory analysis was performed to understand patterns, trends, and relationships within the sales data.

Visualizations were created using:

- Matplotlib
- Seaborn

This step helped identify important sales trends and business patterns before building the final dashboard.

### 3. Power BI Dashboard

After cleaning and analyzing the data, an interactive Power BI dashboard was developed to present key business insights in a visually intuitive format.

The dashboard consists of two main analysis pages.

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales and revenue performance
- Identify monthly revenue and profit trends
- Identify top-performing products

- Compare sales performance across different channels

- Identify high-value customers
